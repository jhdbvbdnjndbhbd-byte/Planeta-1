# Planeta Vivo

Projeto Android inicial do jogo de bichinho virtual Verdinho.

## Como abrir
1. Extraia o ZIP.
2. Abra a pasta `PlanetaVivo` no Android Studio.
3. Aguarde a sincronização do Gradle.
4. Execute no emulador ou em um aparelho Android.

## O que já está incluído
- Alimentar o Verdinho, dar banho, plantar árvores e jogar reciclagem.
- Indicadores de fome, higiene, felicidade e energia.
- Moedas, pontos ecológicos e evolução de nível.
- Salvamento local automático com SharedPreferences.
- Interface em português com mascote em emoji, sem precisar baixar imagens externas.

## Observação
O projeto usa Android Gradle Plugin 8.7.3, Kotlin 2.0.21, compileSdk 35 e AppCompat 1.7.0.
O Android Studio pode solicitar a instalação do Android SDK 35.
